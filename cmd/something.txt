Entities: ParkingSystem, Vehicle, Fare, Booking

ParkingSystem
- ParkingSystemID : UUID
- Bookings[]. (ParkingBookingTable - <ParkingId, BookingId>)
- Fares[] - Array of IDs
- Slots[] - (ParkingSlotsTable - <ParkingId, SlotId>)

Vehicle (DB)
- VehicleType - String
- Model - String
- UUID - UUID

Fare [Per hour]:
- FareId : UUID
- Amount (Paisa) [Int64]
- VehicleType - String

Booking:
- BookingID : UUID
- Vehicle - VehicleId
- Fare - FareId
- Slots[] - Array of IDs

Slot:
- ParkingId - UUID
- StartTime - Timestamp
- EndTime - Timestamp
- isBooked - Boolean

- List Available Slots API
- BookingAPI:
